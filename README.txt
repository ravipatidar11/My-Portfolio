RAVI PATIDAR PORTFOLIO
======================

Files:
- index.html: portfolio content and page structure
- styles.css: responsive layout, typography, light/dark theme styles
- script.js: theme toggle, mobile navigation, current year
- assets/Ravi_Patidar_Resume.pdf: resume download asset (if copied from the uploaded resume)

Preview locally:
1. Extract this ZIP.
2. Open index.html in a modern browser.
3. Internet is only needed for the optional Google Fonts import; the site itself uses system font fallbacks.

Deploy:
- Vercel: import the folder/repository as a static site, or deploy the extracted folder.
- Netlify: drag the extracted folder into the manual deploy area.
- GitHub Pages: upload the files to a repository and enable Pages.

Notes:
- Project GitHub buttons are intentionally not fabricated; the cards say the repository link was not provided.
- Certificate verification links are not fabricated. Add them when you have the exact URLs.
- The contact form was not added because no backend or form service was supplied; email contact works through mailto:.
