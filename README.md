# Ravi Patidar — Portfolio

Personal portfolio website for Ravi Patidar, showcasing projects, skills, experience, education, certifications, and contact information.

## Live website

[https://ravi-portfolio-neon-phi.vercel.app](https://ravi-portfolio-neon-phi.vercel.app)

## Features

- Responsive layout for mobile, tablet, and desktop
- Light and dark themes, with the preference saved in the browser
- Mobile navigation
- Project cards with screenshots, live demos, and GitHub repositories
- Experience timeline and education details
- Certificate links and downloadable resume
- Contact links for email, phone, LinkedIn, and GitHub

## Project files

- `index.html` — page content and structure
- `styles.css` — responsive styling, themes, and layout
- `script.js` — theme toggle, mobile navigation, and current year
- `assets/projects/` — project screenshots used in the project cards
- `assets/ravi_final_resume (1).pdf` — downloadable resume

## Run locally

Open `index.html` in a modern browser. No build step or package installation is required. Internet access is used for the Google Fonts stylesheet; system fonts are used as fallbacks.

## Deployment

This is a static website and is deployed on Vercel. To publish updates, deploy the project folder or connect its repository to a Vercel static-site project.
